# TASI 2020 Crisis Simulator

An interactive trading simulator covering every Tadawul session of 2020: manage a SAR 100,000 portfolio through the oil-price crash, lockdowns, stimulus and the vaccine rally, and benchmark the result against TASI.

## Structure

| Path | Purpose |
|---|---|
| `site/` | The static website (HTML/CSS/JS, no build step) |
| `site/data/content.js` | Sectors, listing dates, macro news wire, financial disclosures |
| `site/data/prices.json` | 2020 closing prices, generated by `scripts/fetch_prices.py` |
| `site/config.js` | Optional Supabase keys for a shared leaderboard |
| `scripts/fetch_prices.py` | Downloads prices from Yahoo Finance into `prices.json` |
| `supabase/schema.sql` | Leaderboard table and access policies |
| `app.py` | Legacy Streamlit version |

## Run locally

```bash
pip install yfinance pandas
python scripts/fetch_prices.py      # writes site/data/prices.json (once)
python -m http.server 8000 -d site  # open http://localhost:8000
```

## Deploy (Cloudflare Pages)

1. Cloudflare dashboard → Workers & Pages → Create → Pages → connect this GitHub repo.
2. Build command: *(empty)* · Build output directory: `site`.
3. Custom domains → add your domain (instant if the domain is on Cloudflare).

## Shared leaderboard (optional)

1. Create a Supabase project and run `supabase/schema.sql` in the SQL editor.
2. Put the project URL and the `anon` public key in `site/config.js`.

Without these keys the leaderboard is kept in each visitor's browser.
